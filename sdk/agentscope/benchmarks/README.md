# AgentScope SDK — Overhead Benchmark Harness Scaffolding

This directory contains measurement scaffolding for evaluating AgentScope SDK performance overhead against **NFR 9.5 (<5% overhead target)**.

> **IMPORTANT (RULES.md §6):** This harness is scaffolding structure built during Week 5. Full benchmark runs and performance claim validations are scheduled for **Week 9**. Do not assert or publish performance metrics from this scaffold prior to Week 9 load testing.

## Running the Benchmark Scaffold

```bash
python -m agentscope.benchmarks.overhead_benchmark
```
